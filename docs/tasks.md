# تاریخچهٔ تغییرات پروژه برای ادامهٔ کار

این سند خلاصهٔ کارهایی است که در گفتگوهای این پروژه انجام شده است. پیش از پیاده‌سازی دوبارهٔ هر مورد، فایل‌ها و وضعیت فعلی Git را بررسی کن؛ تغییرات موجود را تکرار یا برنگردان و فقط درخواست جدید را انجام بده.

## تنظیمات سراسری نمایش

- سامانهٔ تنظیمات از Zustand، i18next، localStorage و API تنظیمات کاربر استفاده می‌کند. بارگذاری و ذخیرهٔ تنظیمات، وضعیت همگام‌سازی و بازنشانی تنظیمات هنگام خروج از حساب در store مدیریت می‌شود.
- تنظیمات زبان، تم، رنگ و فونت در صفحهٔ تنظیمات و ظاهر سراسری پروژه به هم متصل‌اند. تنظیمات معتبر برای کاربر بارگذاری و ذخیره می‌شوند.
- زبان سند، جهت RTL/LTR، عنوان مرورگر و توضیحات meta با زبان انتخاب‌شده هماهنگ می‌شوند؛ تغییر زبان در React نیز با `react-i18next` قابل مشاهده است.
- توکن‌های رنگ سراسری مانند `--app-page-bg`، `--app-surface`، `--app-ink`، `--app-brand`، `--app-brand-deep` و `--app-accent` در `FrontEnd/src/index.css` تعریف شده‌اند. پالت‌های forest، ocean، violet، sunset و monochrome از ویژگی `data-app-color` این توکن‌ها را تغییر می‌دهند.
- حالت‌های light، dark، sepia، contrast و system در CSS سراسری پشتیبانی می‌شوند. انتخاب فونت از تنظیمات به متغیر فونت سراسری متصل است.
- قوانین پایهٔ CSS تا حدی به Tailwind 4 و `@apply` منتقل شده‌اند. قوانین لازم برای توکن‌های پویا، تم‌ها، سازگاری کلاس‌های قدیمی، media query و ترجمهٔ layout در CSS باقی مانده‌اند؛ CSS را بدون بررسی وابستگی‌های سراسری حذف نکن.

## زبان فارسی و انگلیسی

- روش نهایی ترجمه i18next با منابع JSON است: `FrontEnd/src/features/settings/locals/fa.json` و `en.json`. روش runtime قبلی `localizedText.js` حذف شده و نباید دوباره اضافه شود.
- تنظیمات i18next در `FrontEnd/src/features/settings/locals/i18n.js` شامل `keySeparator: false` است؛ بنابراین کلیدهایی از قبیل `settings.title` در فایل‌ها کلید flat هستند. این رفتار را در صورت افزودن کلیدهای جدید حفظ کن.
- دیکشنری قبلی به JSONها منتقل شد، سپس بیش از ۵۰۰ محل استفاده در حدود ۷۰+ فایل JSX/JS به `i18n.t(...)`/`useTranslation()` وصل شدند. رشته‌های ثابت رابط به کلیدها و ترجمه‌ها در دو JSON نگاشت شده‌اند.
- `FrontEnd/src/App.jsx` به زبان در سطح ریشه subscribe می‌شود تا تغییر زبان باعث به‌روزرسانی رابط شود.
- متن‌های دارای متغیر با کلیدهای interpolation صریح در localeها پیاده‌سازی شده‌اند؛ از جمله پیام فعال‌سازی حساب، تأیید ایمیل، alt تصویر پروفایل، لینک پروفایل، وزن و خطاهای اتصال.
- فقط متن رابط و مقادیر enum ثابت را ترجمه کن. نام و محتوای کاربر، پیام، آدرس، کد رهگیری، تاریخ/عدد، مقدار فرم، glyph/آیکون و React element را بی‌دلیل به `i18n.t` نده.
- کلیدهای فارسی و انگلیسی در آخرین بررسی ۶۱۹ کلید متناظر داشتند؛ بررسی AST نیز ۳۶۵ استفادهٔ ثابت ترجمه را پیدا کرد که کلیدهایشان موجود بود.

## Layout و نوبار

- Layout واکنش‌گرا در `FrontEnd/src/features/layout/layout.jsx` استفاده می‌شود: در موبایل نوبار بالای محتواست و در breakpoint دسکتاپ کنار محتوا قرار می‌گیرد. routeهایی که Layout لازم دارند در `FrontEnd/src/features/router/routes.jsx` با آن پوشانده شده‌اند.
- نوبار داشبورد در موبایل به صورت ردیف قابل پیمایش افقی و در دسکتاپ به صورت فهرست عمودی است. scrollbar موبایل استایل اختصاصی دارد.
- عنوان آیتم «نمای کلی» به «داشبورد» تغییر یافته و ترجمه‌اش در هر دو فایل locale ثبت شده است.
- فعال‌بودن آیتم‌های لینک از مسیر فعلی React Router (`NavLink`) می‌آید؛ مسیرهای تو در تو مانند `/inbox/:trackingCode` باید آیتم صندوق ورودی را فعال نگه دارند.
- رنگ متن/آیکون، پس‌زمینهٔ تب فعال و حالت hover نوبار با کلاس `dashboard-nav-item` در `FrontEnd/src/index.css` به توکن‌های `--app-accent` و `--app-brand-deep` وصل شده‌اند. رنگ ثابت برای حالت فعال اضافه نکن؛ خوانایی در تم روشن/تیره و پالت‌های رنگ باید حفظ شود.
- `ShipmentSidebar` صفحهٔ مرسوله‌ها کامپوننت جداگانه‌ای است؛ پیش از تغییر نوبار عمومی بررسی کن که آیا تغییر باید در آن هم اعمال شود.

## رفع lint و اصلاحات جانبی قبلی

- در یکی از دورهای lint حدود ۹ خطا و یک هشدار در چند فایل پیدا و اصلاح شد: مشکل export تابع `exportUsers`، دسترسی به ref حین render و وابستگی effectها، importهای بلااستفاده و setState مستقیم داخل effect.
- چرخهٔ انیمیشن Header ادمین با ساخت `SplitType` داخل effect و cleanup مربوط به GSAP اصلاح شد.
- stateهای صفحهٔ پروفایل و پیام مستقیم هنگام تغییر شناسهٔ route بررسی/ایمن شدند تا دادهٔ شناسهٔ قبلی نمایش داده نشود.
- پس از مهاجرت ترجمه، مقادیر پویا و غیررشته‌ای در چند کامپوننت (از جمله کارت‌های اطلاعات، فرم‌ها، تعدادها، glyphها و داده‌های کاربر) از مسیر ترجمه خارج شدند. این اصلاحات را در صورت کار مرتبط حفظ کن.
- فایل پیوست‌شدهٔ `FrontEnd/src/features/admin/components/adminPageHeader.jsx` در درخواست‌های اخیر صرفاً به‌عنوان زمینه دیده شد؛ تغییر مستقیمی در آن درخواست‌ها انجام نشد.

## بررسی‌های انجام‌شده و مورد شناخته‌شده

- `npm run build` چندین بار موفق بوده است.
- `npx eslint src` پس از مهاجرت اصلی ترجمه موفق بوده؛ در آخرین تغییر نوبار نیز ESLint فایل‌های نوبار موفق شد.
- `git diff --check` اجرا شده و خطای whitespace گزارش نکرده است. هشدارهای Git دربارهٔ تبدیل LF به CRLF در Windows هستند.
- هشدار build مربوط به chunk صفحهٔ About (حدود ۶۴۳ KB، بیشتر از ۵۰۰ KB) از قبل شناخته‌شده و هنوز بهینه‌سازی نشده است؛ فقط در صورت درخواست مرتبط سراغ آن برو.
- آخرین تغییرات نوبار در working tree شامل `NavbarSide.jsx`، `dashboearNavItems.jsx`، `navItems.jsx`، `index.css` و دو فایل JSON است. اسناد همین تاریخچه در `docs/tasks.md` قرار دارند.
